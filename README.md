Project Title:

Student Log In Portfolio

Project Description:

A portfolio generator for IT students. Users register, build a profile with projects, skills, and education, choose a template, and publish a shareable portfolio link. Built with Laravel and deployed on Vercel with a Supabase PostgreSQL database.

Technologies Used:

HTML - structures the website.
CSS - layout, appearance, and its three portfolio templates.
JavaScript - implements application functionality.
Vercel - hosts the published website.
Supabase - provides the online database.
GITHUB - is a cloud-based platform for storing, versioning, and collaborating on code.

the service where your data is stored and managed (in your project, Supabase’s PostgreSQL).
